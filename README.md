# Sales Performance Dashboard (Excel)

Interactive sales performance dashboard built in Excel using slicers, PivotTables, PivotCharts, and dynamic KPI cards to track sales, profit, and orders across cities and product categories.

**Tool:** Microsoft Excel | **Features:** Slicers, PivotTables, PivotCharts, dynamic KPI cards

## 🔑 What's in the Dashboard

- **KPI Cards** — Total Sales, Total Profit, Total Orders
- **Sales by City** — bar chart
- **Profit by Category** — pie chart
- **Top Products** — horizontal bar chart
- **Monthly Sales Trend** — line chart
- **Interactive Slicers** — filter by city, category, and more

## 🔑 Key Insight

Bangalore leads in sales, while the Furniture category contributes the highest profit.
